## 2. `schema.py`（Authoring Schema DSL）

```python
class Person(Entity):
    source_id: str = Identity()
    country: str = Field(cardinality="functional")
    tags: str = Field(cardinality="multi", aliases=["labels"], display_name="Tags")
```

## 3. `rule.py`（Authoring Rule DSL）

文件：`/Users/zhenzhili/symbolic_agent/.tutorial_work/example_project/authoring/rule.py`

```python
country_rows = Rule(
    version="v1",
    select=["E", "C"],
    body=[Pred("person:country", "$E", "$C")],
    public=True
)
```

## 4. `derivation.py`（Authoring Derivation DSL）

文件：`/Users/zhenzhili/symbolic_agent/.tutorial_work/example_project/authoring/derivation.py`

```python
country_drv = Derivation(
    head=Person.country(person=E, country=country),
    materialize_as="fact",
    body=[Pred("person:country", "$E", "$country")],
    mode="python",
    temporal_view="record"
)
```

说明：推荐使用蓝图风格 `head + materialize_as`。当前 compile 会基于 `SchemaIR` 将 `head=Person.country(...)` lowering 到 `person:country` 与位置映射 `head_vars=["$E", "$country"]`；该位置映射语义按目标谓词 `arg_specs` 逐位对应，不是按 `Person` 实体字段投影。

## 8. 生成审计包与静态审计页面

文件：`/Users/zhenzhili/symbolic_agent/.tutorial_work/example_project/scripts/build_audit_site.py`

```python
from pathlib import Path
import shutil
import json

from factpy_kernel.authoring.schema_compile import compile_authoring_schema_v1
from factpy_kernel.export.package import ExportOptions, export_package
from factpy_kernel.store.api import Store
from factpy_kernel.audit.static_ui import render_audit_static_site

authoring_schema = {
    "entities": [
        {
            "entity_type": "Person",
            "identity_fields": [{"name": "source_id", "type_domain": "string"}],
            "fields": [
                {"py_name": "country", "name": "country", "type_domain": "string", "cardinality": "functional"},
                {"py_name": "tags", "name": "tags", "type_domain": "string", "cardinality": "multi"}
            ]
        }
    ]
}

root = Path("/Users/zhenzhili/symbolic_agent/.tutorial_work/example_project")
registry_dir = root / "registry"
pkg_dir = root / "audit_pkg"
site_dir = root / "audit_site"

schema_ir = compile_authoring_schema_v1(authoring_schema)
store = Store(schema_ir=schema_ir)

export_package(store, pkg_dir, ExportOptions(package_kind="audit", policy_mode="edb"))

events_path = registry_dir / "authoring_apply_events.jsonl"
if events_path.exists():
    shutil.copyfile(events_path, pkg_dir / "authoring_apply_events.jsonl")

site_manifest = render_audit_static_site(pkg_dir, site_dir)
print(json.dumps(site_manifest, ensure_ascii=False, indent=2))
```

运行：

```bash
python .tutorial_work/example_project/scripts/build_audit_site.py
```

然后打开：

- `/.tutorial_work/example_project/audit_site/index.html`
- `/.tutorial_work/example_project/audit_site/authoring_apply_events.html`
- `/.tutorial_work/example_project/audit_site/authoring_apply_runs/example-req-001.html`

## 9. 常见问题（FAQ）

### Q1：`apply-execute` 返回 `status=error` 但 CLI exit code 是 0？

这是当前设计：业务级错误通过 JSON DTO 表达（结构化 diagnostics），而不是直接让 CLI 进程崩溃。

请检查：

- `apply_execute.status`
- `apply_execute.diagnostics`
- `transaction.failure_phase`

### Q2：为什么 `audit_site` 的 `runs/` 或 `decisions/` 页面是空的？

因为示例脚本里构造的是空 `Store(schema_ir=...)`，没有推理运行数据。本教程重点演示 authoring apply 事件接入静态审计页面。

### Q3：`v2` 为什么还可能不是完全严格事务？

当前 `prevalidate_no_partial_strict_v2` 是最小可执行版，尚未实现 rollback/compensation。详见教程 6。
