## 2. Published Capability Baseline

The lifecycle/assets sequence from 2026-05-12 remains complete:

- Public SDK vocabulary is `Inference`.
- Public wire / registry vocabulary is `inference`.
- Authoring assets are persisted through `fg.rules.*` and `fg.inferences.*`.
- Workspaces are persisted through `FactGraph.create(path=...)`,
  `fg.save(...)`, and `FactGraph.load(path, schema_classes=[...])`.
- Application runtime authority is established through:
  - `kernel.application.authoring_runtime`
  - `kernel.application.workspace_runtime`
  - `kernel.application.schema_mutation_runtime`

New schema capabilities from 2026-05-13:

- `fg.schema.add(EntityCls)` and `fg.schema.add(schema_classes=[...])`
  support additive entity-class schema extension.
- `SchemaAddResult(old_digest, new_digest, added_entities, added_fields)` is
  public through `kernel.sdk`.
- Same-entity replacement classes may add non-identity fields.
- Superseded classes/descriptors raise `SDKStoreError`; use the post-add class.
- Existing assertions are not backfilled. Missing added single fields read as
  `None`; missing added multi fields read as `()`.
- Ledger and registry schema digests are updated immediately after validation.
- Workspace manifest schema digest remains save-time state and updates only on
  explicit `fg.save(...)`.

Confidence / evidence cleanup from 2026-05-13:

- `CandidateSet.confidence` and `CandidateSet.confidence_kind` remain
  internal/session compatibility carriers.
- Service candidate DTOs and candidate inventory omit those legacy fields by
  default.
- Runtime accept still parses old echoed `confidence` / `confidence_kind`
  fields, but does not persist them into assertion meta by default.
- Generic `meta.confidence` remains a ledger meta row only; it is not projected
  into shared derived annotations.
- Legacy confidence differences do not affect duplicate detection.
- ProbLog export no longer falls back to generic `meta.confidence`.
- PyReason keeps adapter-native `pyreason/semantic/bound_*` rows and filters
  generic confidence metadata from shared projections.
- Candidate evidence trees do not lift generic assertion `meta.confidence` into
  default evidence/certainty display.
