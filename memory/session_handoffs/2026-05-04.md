### 4.3 DTO shape (frozen Step 0.B)

**`CheckRequest` (intent-only):**
- `plan: CompiledDerivationPlan` (single — multi-plan rejected at construction)
- `binding: BindingItems` (sorted `(str, value)` tuple; `$`-prefix variable names enforced; duplicate-impossible)
- `engine: Literal["native","souffle","problog","pyreason"]` (required, no default)
- **NO** `store`, `registry`, `engine_options`, `query_id`, `run_id`, or precomputed `rule_ref_resolutions` (Python dataclass `TypeError` on unknown kwargs is the anti-regression gate)

**`CheckResult`:**
- `status: Literal["passed","failed","unsupported","invalid_request"]`
- `requested_binding: BindingItems` (echo, normalized)
- `matched_count: int | None` — `≥1` passed; `=0` failed; `=None` unsupported / invalid_request
- `matched_binding: BindingItems | None` — present only on passed (primary)
- `evidence_envelope: EvidenceEnvelope | None` — present only on passed
- `errors: tuple[ErrorDTO, ...]` (reuse `application.protocol.common`)
- `warnings: tuple[WarningDTO, ...]`

**`EvidenceEnvelope`:**
- `engine: Literal[...]`
- `support_kind: str` (`native_binding_v1` / `souffle_witness_v1` / `problog_provenance_v1` / `pyreason_provenance_v1`)
- `support_digest: str` (sha256 token)
- `branch_index: int | None` — None for engines without per-branch concept (problog/pyreason)
- `engine_payload: SupportArtifact | ProvenanceEnvelope` — typed Union; **NEVER** flattened
- `branch_atom_projection: None = None` — slot reserved for future Layer 3 walkable view; **MVP always None**; `None` ≠ degraded evidence

### 4.4 Runtime entry

```python
def check_derivation_binding(
    request: CheckRequest,
    *,
    store: Store,
    registry: RuleRegistry | None = None,
) -> CheckResult
```

Side-channel pattern (`store`, `registry` are runtime kwargs, NOT DTO fields) — mirrors `evaluate_derivation_plans(request, *, store, registry)`.

### 4.5 Algorithm per engine

| Engine | Path | Match source | Primary sort key | engine_payload |
|---|---|---|---|---|
| native | `evaluate_native_where` (unified for complete+partial) | final bindings → subset match | `(branch_index, binding_items)` | `SupportArtifact` (`native_binding_v1`) |
| souffle | `evaluate_derivation_plans` then `Store._lookup_support_artifact(digest)` | `SupportArtifact.binding_items` | `(branch_index, binding_items, candidate_key)` | `SupportArtifact` (`souffle_witness_v1`) |
| problog / pyreason | `evaluate_derivation_plans` then `Store._lookup_provenance_envelope(digest)` | head-var positional alignment from `candidate.payload['terms']` | `(candidate_key, binding_items)` (no branch_index) | `ProvenanceEnvelope` (`{engine}_provenance_v1`) |

### 4.6 Critical algorithm rules (anti-regression tested)

1. Native partial binding **MUST** enumerate full bindings first, then subset-match. **NEVER** `_branch_satisfies(partial)` directly (silent wrong `failed`; topic §7.1 trap).
2. EvidenceEnvelope built from primary FULL binding (never user partial; §7.1).
3. Per non-native: representability precheck **before** evaluate (Step 0.C C6) — non-representable shape → `status=unsupported` *before* any adapter call (avoids vacuous "0 candidates → unsupported" bug).
4. `candidate_ref` term in payload → `_UNREPRESENTABLE_TERM` sentinel → skip in binding extraction (not None — avoids polluting binding dict).
5. `$`-prefix `head_var_names` → variable reference; bare names are literal head args (`resolve_head_ref` convention in `_builders.py`).
6. Internal typed lookup (`Store._lookup_support_artifact` / `_lookup_provenance_envelope`) over public `explain_*` (which return rendered dict) — Check is internal application code; no need for serialize round-trip.

### 4.7 Status semantics

- `passed`: matched_count≥1, primary matched_binding + evidence present
- `failed`: representable + evaluated + no match → matched_count=0, others None
- `unsupported`: NOT representable for engine/output shape → matched_count=None, errors required
- `invalid_request`: semantically invalid request → matched_count=None, errors required

Critical: `failed` ≠ `unsupported` (per Step 0.C C6); `matched_count=None` distinguishes "didn't evaluate" from "evaluated, no match".

### 4.8 Error codes

- `UNKNOWN_VARIABLE_IN_BINDING` — semantic invalid_request
- `REGISTRY_REQUIRED` — ruleref present, no registry (preflight)
- `RULE_REF_UNRESOLVABLE` — registry missing rule_id@version (with `details.reason` from `RuleCompileError`)
- `BINDING_NOT_REPRESENTABLE` — non-native engine + body-only binding
- `ENTITY_TARGET_NOT_REPRESENTABLE` — non-native engine + entity-targeted plan
- `MULTI_HEAD_PLAN_NOT_SUPPORTED` — DTO post_init rejection
- `CHECK_INTERNAL_UNKNOWN_ENGINE` — defensive `CheckRuntimeError` for engine-literal drift

Cycles / version-mismatch deliberately NOT classified — would require parsing brittle exception text; native eval surfaces them as runtime errors.

## 5. Architectural Decisions Locked

### 5.1 Concept (topic §1.3)

Check is the **verify-given dual** of evaluate. Same 8-atom semantics, opposite direction.

### 5.2 Binding semantics (topic §3.7 + Step 0.C)

- **Complete binding:** subset match equals exact match
- **Partial binding:** subset match = "is there a final binding extending user's partial?" Implementation: full enumerate → subset match → primary. NEVER initial-env injection.

### 5.3 Engine scope (Step 0.A — Option IV "representability-gated multi-engine")

- Not native-only; not non-native-as-second-class; not strict-equal across engines
- Per-engine answers when its candidate payload / evidence shape supports the binding shape
- Architectural seam: `extract_match_binding(candidate, evidence_or_provenance, requested_binding) -> BindingItems | unsupported`
- Per-engine impl:
  - native: bypasses seam (final bindings from `evaluate_native_where`)
  - souffle: `SupportArtifact.binding_items`
  - problog / pyreason: head-var positional alignment from `candidate.payload['terms']`; body-only or entity-targeted → `unsupported`; no provenance fallback in MVP

### 5.4 Evidence (topic §6.5 + §6.9, Step 0.B B8/B9/B10)

3 concept layers, one typed-Union envelope:

```
EvidenceEnvelope {
  common envelope    : engine, support_kind, support_digest, branch_index?
  engine-native      : SupportArtifact | ProvenanceEnvelope (NEVER flatten)
  optional projection: branch_atom_projection: None  # MVP slot reserved
}
```

`branch_atom_projection=None` ≠ degraded — anti-regression test enforces.
`engine_payload` field renamed from `native_payload` post Step 0.B (`native_payload` misled as "for native engine only"); supersede note in topic doc top.

### 5.5 Drift prevention (topic §7, validated across 3 blind reviews + post-impl audit)
