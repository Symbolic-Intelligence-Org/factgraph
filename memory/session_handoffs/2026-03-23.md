## 8. Known Gaps

### 8.1 Composed ruleref provenance (CRITICAL — blocks full ECSS demo)

`where_compile.py` does not support `ruleref` atom kind in query export. Flat rules get provenance; composed rules (top-level compliance) cannot. This is the single most important next implementation task.

### 8.2 Audit round-trip for provenance

Souffle proof trees are not yet persisted in audit packages. `run_package_provenance` runs at demo time, not export time. Long-term: provenance should be materialized alongside `certainty_summaries.jsonl`.

### 8.3 Evidence tree metadata transparency

Only `confidence` flows from fact metadata into evidence tree nodes. Other meta fields (source, analyst, method, date) are stored in ledger but invisible in tree.

### 8.4 Certainty v1 limitations (documented, frozen)

Flat-only, single-rule, no recursion, no OR branches, no negation. See ADR v2.
