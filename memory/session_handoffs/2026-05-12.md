## § 7. Frozen Contracts

These contracts **must not be reopened** without explicit user approval. They were locked across the 4 slices and verified through G1-G4 baselines.

1. **Public SDK uses `Inference`**, not `Derivation`. No public `Derivation` alias.
2. **No public `DerivationRef`** ever. Reference types for rules and inferences are `SavedRuleRef` / `SavedInferenceRef` (asset handles) and `RuleRef` (where-clause carrier, **distinct from** asset handle).
3. **`RuleRef` is a where-clause carrier only**, not a runnable rule selector. `fg.eval.run(rule_ref)` raises.
4. **Saved refs are load handles only.** `fg.eval.run(SavedRuleRef(...))` / `fg.eval.evaluate(SavedInferenceRef(...))` raises. Use `fg.rules.load(ref)` / `fg.inferences.load(ref)` first.
5. **`Inference.to_authoring_payload()` emits `derivation_id` substrate key.** This is the compiler-facing payload format, deliberate substrate preservation. Renaming it would cascade into core candidate protocol.
6. **`CandidateSet.derivation_id` / `CandidateSet.derivation_version` are substrate vocabulary.** Service runtime evaluate response candidate payloads retain these field names. This is documented residual mixed vocabulary, intentional.
7. **`standard="derivation_v1"` provenance standard identifier stays.** It is substrate version vocabulary, decoupled from public class names.
8. **`CompiledDerivationPlan`, `DerivationEvaluateRequest`, `DerivationAcceptRequest` are internal application protocol DTOs.** No public surface; advanced/internal access through `kernel.application.protocol.derivation` only.
9. **`SDKRegistry` is internal/advanced.** Not in `kernel.sdk.__all__`. Importable from `kernel.sdk.registry` for tests/advanced use.
10. **`fg.queries` namespace is intentionally absent.** Negative guard locks it out until query persistence is designed.
11. **`fg.eval.evaluate_compiled` / `accept_compiled` are not public.** Private `_evaluate_compiled_derivation_plans` preserved for internal `evaluate(...)` lowering only.
12. **`_SDKBatchTx.save(obj)` is unchanged** — it stages an object into a batch transaction. Verb collision with `FactGraph.save(...)` is resolved by receiver-object disambiguation.
13. **`fg.package.export_package(...)` is distinct from `fg.save(...)`.** Package = portable distribution artifact. Workspace = continued editing/running.
14. **`fg.views` is in-memory only.** Excluded from `fg.save(...)` per Q14.
15. **Artifact sidecars are out of workspace scope.** `fg.save(...)` does not copy/preserve them.
16. **Audit/evidence round files are out of workspace scope.** `fg.save(...)` does not include them.
17. **`FactGraph.load(...)` requires `schema_classes=[...]`** in the current slice. Class-less dynamic load deferred.
18. **`fg.save(...)` is idempotent** when graph is bound to its file-backed workspace path with no in-memory changes.
19. **`fg.save(other_path)` uses SQLite backup/copy** for the ledger when source and target differ; same-path saves are no-op for ledger files.
20. **4-anchor schema validation in `FactGraph.load(...)`**: manifest digest + ledger digest + registry digest + provided classes digest must all agree.
21. **`workspace_runtime` and `authoring_runtime` own persistence orchestration.** SDK managers are thin shells; they must not duplicate filesystem registry/workspace logic.
22. **`from_schema_classes([...])` does not accept `path=`** (W19b). The advanced lower-level constructor stays focused on the 5 original kwargs.
23. **Sacred refs untouched.** `release/0.1.x`, `v0.1.0-rc.1`, `origin/v0.1-oss-prep`, and 17 milestone branch refs are immutable.
