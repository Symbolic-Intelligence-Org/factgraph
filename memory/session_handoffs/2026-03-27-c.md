## 7. Known Gaps

### 7.1 D-VC4 Research Spike (RECOMMENDED NEXT)

**The critical open question**: Can PyReason express bounded-value reasoning through its rule syntax?

**Known constraints**:
- `rule_parser.py` treats multi-variable node atoms as edge predicates
- No native "value variable" concept for node predicates
- Possible approaches need validation:
  - Synthetic edge encoding
  - Custom label naming conventions
  - PyReason API extensions (out of scope?)

**This determines L3b scope**: If D-VC4 has no feasible solution, L3b is limited to bounded materialization + bound-summary extraction (D-VC2 + D-VC3 only). If D-VC4 can be resolved, L3b includes rule-level value-carrying.
