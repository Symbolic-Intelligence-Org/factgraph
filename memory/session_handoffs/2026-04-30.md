## 4. Behavior Changes Landed

### Identity contract

Every SDK `Entity` must now define at least one `Identity(primary_key=True)`.

- zero Identity still raises the existing schema error
- only secondary `Identity()` now raises `SDKSchemaError`
- primary + secondary identity remains legal
- multiple primary identities are not blocked, leaving room for future composite key work

### Write cardinality

Application write planning now enforces:

- `set` requires a `single` field
- `add` requires a `multi` field

Mismatches surface as `FIELD_CARDINALITY_MISMATCH`, and SDK `set/add` wraps the mismatch as `CardinalityError`.

### SDK `set/add`

`SDKStore.set/add` now route through application write-plan / apply-plan.

User-visible effects:

- identity and `<T>:exists` are materialized through the application path
- unmanaged target e_ref raises `SDKStoreError(code="UNRESOLVABLE_E_REF")`
- unmanaged entity_ref value raises the same actionable SDK error
- returned assertion id remains the field mutation assertion id

`sdk.ingest` keeps its DTO-oriented legacy fallback by directly calling write-protocol primitives when needed. This is intentional and recorded in the blueprint.

### User journey probe

`src/kernel/tests/test_v01_onboarding_journey.py` now locks a kernel-only native onboarding path:

`ref → set/add → get → query → evaluate(native) → accept → export audit package`

The probe is test-backed. A runnable monorepo notebook mirror now exists at `examples/10_v01_onboarding_journey.ipynb`; it is still excluded from the release-surface allowlist until an examples add-back pass is scoped.

### SDK polish

- `SDKDSLError` now inherits `SDKError`
- `SDKStore.__repr__` is concise and readable

### Docs boundary

- SDK user guide no longer points v0.1 users at `domains.ecss.sdk_helpers`
- `docs/SECURITY.md` is kernel-only; HTTP service auth moved to `docs/SECURITY_monorepo.md`
- audit overview fences `service.static_ui` and `domains.ecss.*` as off-wheel consumers / optional domain bundles
- examples README separates default-wheel kernel, optional-engine kernel, and private monorepo demos
