# 教程 5：导出审计包与静态审计页面

本教程演示如何生成 `audit package`，并把 `authoring_apply_events.jsonl` 接入静态审计页面（概念层 UI）。

> 这里的“UI”是静态 HTML/JSON 产物，用于查看和排障；不是完整前端应用。

## 1. 生成最小 audit package（Python API）

在项目根目录执行下面脚本（可保存为 `/.tutorial_work/build_audit_pkg.py`）：

```python
from pathlib import Path
import json
import shutil

from factpy_kernel.authoring.schema_compile import compile_authoring_schema_v1
from factpy_kernel.export.package import ExportOptions, export_package
from factpy_kernel.store.api import Store
from factpy_kernel.audit.static_ui import render_audit_static_site

authoring_schema = {
    "entities": [
        {
            "entity_type": "Person",
            "identity_fields": [{"name": "source_id", "type_domain": "string"}],
            "fields": [
                {"py_name": "country", "name": "country", "type_domain": "string", "cardinality": "functional"}
            ],
        }
    ]
}

root = Path("/Users/zhenzhili/symbolic_agent/.tutorial_work")
registry_dir = root / "registry"
pkg_dir = root / "audit_pkg"
site_dir = root / "audit_site"

schema_ir = compile_authoring_schema_v1(authoring_schema)
store = Store(schema_ir=schema_ir)

export_package(store, pkg_dir, ExportOptions(package_kind="audit", policy_mode="edb"))

events_path = registry_dir / "authoring_apply_events.jsonl"
if events_path.exists():
    shutil.copyfile(events_path, pkg_dir / "authoring_apply_events.jsonl")

site_manifest = render_audit_static_site(pkg_dir, site_dir)
print(json.dumps(site_manifest, ensure_ascii=False, indent=2))
```

运行：

```bash
python .tutorial_work/build_audit_pkg.py
```

> 提示：这个示例里的 `Store(schema_ir=schema_ir)` 是空 store，因此 `runs/*.html` / `decisions/*.html` 可能为空。
> 本教程重点是验证 `authoring_apply_events.jsonl` 能否被静态审计页面消费。

## 3. 打开静态页面（本地查看）

你可以直接用浏览器打开：

- `/.tutorial_work/audit_site/index.html`
- `/.tutorial_work/audit_site/authoring_apply_events.html`

如果你想本地起一个静态服务（可选）：

```bash
cd /Users/zhenzhili/symbolic_agent/.tutorial_work/audit_site
python -m http.server 8000
```

然后访问：`http://127.0.0.1:8000/`

重点查看 `authoring_apply_runs/<req>.html` 页面中的：

- `execution_path`
- `execution_path_label`
- `Idempotency`
- `Transaction`
- `failure_summary`
- `action_stats`

## 4. 搜索与索引（概念层）

静态站点内提供：

- `search.html`（基于 `ui_index.json` 的前端搜索）
- `indexes/*.html`（按 `event_kind/error_class/pred_id` 等）

如果导入了 `authoring_apply_events.jsonl`，你还可以按这些维度排查：

- `apply_request_id`
- `status`
- `section`

### 4.1 建议的查看顺序

1. `authoring_apply_events.html`（先看有哪些请求）
2. `authoring_apply_runs/<req>.html`（看单次 apply 聚合视图）
3. `search.html`（按 `apply_request_id/status/section` 精确定位）
