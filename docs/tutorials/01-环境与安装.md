# 教程 1：环境与安装

本教程确认你能在本机运行 `factpy_kernel` 的 Authoring CLI，并了解哪些组件是可选依赖。

## 1. 前置条件

- Python 3.10+（建议使用虚拟环境）
- 项目源码目录：`/Users/zhenzhili/symbolic_agent`
- 可选：Soufflé（用于真实引擎执行；未安装时 runner 会 fallback 到 `noop`）

## 2. 安装（开发模式）

在项目根目录执行：

```bash
cd /Users/zhenzhili/symbolic_agent
pip install -e .
```

如果你不希望安装到当前环境，也可以直接使用 `python -m ...` 方式运行 CLI（本文教程默认这么做）。

## 3. 检查 Authoring CLI

```bash
cd /Users/zhenzhili/symbolic_agent
python -m factpy_kernel.authoring.cli --help
```

预期你能看到这些子命令（顺序可能不同）：

- `preflight`
- `workflow-dry-run`
- `apply-execute`
- `registry-list`
- `registry-show`

## 4. （可选）检查 Soufflé

```bash
souffle --version
```

如果未安装：

- 不影响 Authoring / Registry / Audit 静态页面教程
- 影响真实 Soufflé runner 教程（可先使用 `noop` 路径或跳过）

## 5. 建议的练习目录

为了避免污染源码目录，建议为教程创建一个工作目录：

```bash
mkdir -p /Users/zhenzhili/symbolic_agent/.tutorial_work
```

后续教程会在这个目录下创建：

- `authoring_schema.json`
- `schema.py` / `rule.py` / `derivation.py`
- `registry/`
- `audit_pkg/`
- `audit_site/`
