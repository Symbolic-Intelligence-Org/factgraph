## Decision Notes

- Initial candidate scope is replay-time `disable_condition` over the v0.1.2 module IR substrate.
- The v0.1.1/v0.1.2 boundary remains active: evidence is read-only, compile / validate / evaluate is authoritative, and replay produces temporary variants rather than persistent rule mutation.
- Step 0 is complete; implementation may proceed under the scoped native-overlay design.
- Step 0 rejected physical atom deletion because it shifts support keys and module-map locators.
- Step 0 rejected adding a no-op/truth atom because it would expand the where language and leak into validators/backends.
- Step 0 selected native-only runtime overlay as the smallest implementation path: evaluator/support-capture loops already enumerate branch atoms, so `continue` can skip disabled locators without changing downstream atom indices.
