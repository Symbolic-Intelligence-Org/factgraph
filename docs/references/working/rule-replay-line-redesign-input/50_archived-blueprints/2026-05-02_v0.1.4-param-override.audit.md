## Decision Notes

- Initial candidate scope is replay-time parameter override over the v0.1.2 module IR + v0.1.3 native overlay substrate.
- The v0.1.1-v0.1.3 boundary remains active: evidence is read-only, compile / validate / evaluate is authoritative, and replay produces temporary variants rather than persistent rule mutation.
- Do not implement before Step 0 answers the source-backed questions in section 8 of the blueprint.
- Default public-surface posture is narrow: prefer replay-only APIs over adding general `SDKStore.evaluate(...)` overlay kwargs unless source-backed evidence proves otherwise.
- Step 0 can legitimately end with a negative scope decision. Here it did:
  discovering that a proposed capability decomposes into multiple semantic
  families is a valid outcome and prevents false abstraction.
