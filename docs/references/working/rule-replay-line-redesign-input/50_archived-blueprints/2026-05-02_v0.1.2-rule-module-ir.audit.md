## Decision Notes

- Initial scope is L2 rule module IR / objectized rule-body substrate. It must not reopen v0.1.1 preview boundaries unless explicitly scoped.
- v0.1.1 rule replay remains the base contract: operate on rules/derivations, keep evidence read-only, and use compile / validate / evaluate as runtime truth.
- Step 0 must resolve module ownership, module identity, locator compatibility, first operation scope, evidence mapping, RuleRef support, and docs impact before implementation begins.
- Step 0 ownership decision: first module IR substrate belongs in `kernel.authoring`, with SDK ergonomics and core runtime integration kept separate.
- Step 0 identity decision: generated module ids are owner/path-scoped and stable; cross-rule sharing requires explicit `shared_id` / library identity in a later scope.
- Step 0 operation decision: v0.1.2 is a structural carrier/lowering upgrade. It keeps v0.1.1 replay behavior compatible and does not add `disable_condition` or `param_override`.
