# Code of Conduct

This project expects professional, respectful collaboration.

## Expected Behavior

- Discuss technical disagreements with concrete evidence and actionable alternatives.
- Keep review comments focused on code, behavior, documentation, tests, and project direction.
- Be direct without being hostile.
- Respect maintainer decisions about scope, sequencing, and release readiness.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Personal attacks in issues, pull requests, discussions, or other project spaces.
- Publishing private information or credentials.
- Repeatedly derailing technical discussions after maintainers have closed a decision.

## Reporting

Report conduct concerns to the project maintainers through the repository's private security or maintainer contact channel. If no private channel is available yet, avoid posting sensitive details publicly and ask for a maintainer contact path.

Maintainers may remove comments, close discussions, block accounts, or take other reasonable action to protect the project space.
