# Foundations

Stable architecture principles and module docs conventions. Content is foundational governance — slow-changing; updated only via deliberate slice work.

## Contents

- `architecture_principles.md` — stable design philosophy, system boundaries, long-term direction.
- `module_docs_convention.md` — module `docs/README.md` minimum structure, writing conventions, update triggers, starter template.

## Authority

Both files are **current truth for the conventions they describe**. Modules cite back to them; new modules follow `module_docs_convention.md` from creation.

For per-task constraints see `workflow/blueprints/`. For per-decision constraints see `workflow/design/decisions/`. Foundations sit above all of those.
