## 4. PyReason Operational Manual (from real-engine experiments)

**Verified constraints**:
1. Edge labels → graph attributes (via `load_graph`). Node labels → `add_fact()`
2. Mixing graph attr + add_fact on same label blocks rule propagation
3. Default body clause threshold = `[1,1]` — rejects non-`[1,1]` seeds. Fix: explicit `body_predicate_bounds`
4. Head bound = static annotation: `popular(x) : [0.8, 0.9] <- ...` produces `[0.8, 0.9]` derived bound
5. Cross-label derivation (`b(x) <- a(x)`) — NOT verified to work; only same-label propagation confirmed
6. `pr.get_rule_trace(interp)` → 2 DataFrames (node trace + edge trace)

**Observed but not frozen**:
- `pr.add_annotation_function()` exists — may enable dynamic head bound computation (research spike needed)
- `pr.reset()` has global state residue within same process
