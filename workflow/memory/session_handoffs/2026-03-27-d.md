## 7. Frozen Contracts

**Prior contracts 1-51 remain frozen.** This session adds:

52. **pyreason_bounded is adapter-local** — `pyreason_bounded: true` on predicate spec; only PyReason adapter reads it. Not a core schema feature.
53. **Bounded routing requires 3 hard AND** — numeric type_domain + pyreason_bounded + value in [0,1]. Missing any → existence fallback.
54. **D-VC4 closed: infeasible** — PyReason parser hardcodes variable count as node/edge classifier. No value variable concept for nodes. Label suffix comparison is deprecated.
55. **Bounded extraction = str(lower_bound)** — Derived bounded predicates output `str(lo)` not `"true"/"false"`.
56. **EDB bounded facts = point interval** — Ledger float value → `bound=(v, v)`. Supports canonical `0x...` float64 format.
57. **Canonical float64 parsing** — `_parse_bounded_float()` handles both decimal and `0x...` bit-pattern formats from Ledger projections.

**Partially superseded**: Contract #49 (D7) — existence model remains default but bounded numeric is now an extension for predicates satisfying the 3 hard AND conditions.
