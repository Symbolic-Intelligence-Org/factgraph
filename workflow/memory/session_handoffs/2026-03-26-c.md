## 8. Known Gaps / Risk Assessment

### 8.1 PyReason Execution Surface v0 (RECOMMENDED NEXT)

**What exists**: Complete adapter-local vertical slice (schema → session → runner → accept → ledger).

**What's missing**:
- `Store.evaluate(mode="pyreason")` registration
- WHERE → PyReason rule compilation beyond PredAtom + LogicVar
- CandidateSet output format for PyReason results
- Capability gate for PyReason-specific WHERE atoms
- Provenance integration with audit pipeline

**Why deferred**: Registering with Store.evaluate freezes core-facing contracts. The adapter-local slice needs real-world validation first.

### 8.2 Rule Compile Expansion

**v0 supports**: `PredAtom` + `LogicVar` + string/number literals.
**Missing**: `CompareExpr`, `NotExpr`, `RuleRefAtom`, `ExistsAtom`. These require understanding PyReason's equivalents (if they exist).

### 8.3 Entity Identity / entity_ref Alignment

Accept helper uses synthetic `idref_v1:{Type}:{id}`. Proper entity registry integration pending.
