43. **D1: EvaluateMode gate** — Add `"pyreason"` to closed Literal. ~5 lines core change.
44. **D2: No engine_options for v0** — `PyReasonRunConfig` hardcoded in adapter. No core signature extension.
45. **D3: WhereIR → PyReason compiler** — New compiler for lowered `("pred", pred_id, terms)` atoms. PredAtom compiler coexists for adapter-local runner.
46. **D4: Reuse engine_no_witness_v1** — No new support kind. No explain path.

48. **D6: Annotation side-channel via Store pending state** — `EngineEvaluatorFn` return type stays `list[CandidateSet]`. Annotations via `store._engine_pending_annotations[run_id]`. Lifecycle: evaluate → accept → persist → clear.
49. **D7: PyReason v0 fact semantics = attribute existence model** — Node fact: `graph.nodes[ref][pred] = 1`. Derived: `"true"/"false"`. No value variables. Value-carrying deferred to v1.
50. **D8: v0 only requires Derivation.engine_ext** — Rule.engine_ext deferred to v1.
51. **D9: EDB default bounds [1.0, 1.0]** — Non-PyReason Ledger facts enter PyReason as ground truth.
